# Privacy holati

JOVO default-private yo‘nalishda. Direct chat tarixi faqat aktiv `ChatMember` uchun beriladi; block va direct-message policy serverda tekshiriladi. Message edit/delete/reaction ham membershipni qayta tekshiradi.

## Hozir ishlamaydi

- To‘liq phone/email/avatar/last-seen/story/call privacy matrix.
- Data export/delete queue va backup expiry.
- Report/appeal moderation lifecycle.
- Secret Chat/E2EE: `OFF`; transport xavfsizligi E2EE deb ko‘rsatilmaydi.
- AI providerga chat yuborish: sozlanmagan va avtomatik amalga oshirilmaydi.

Yangi media, bot, AI, location va call modullari explicit permission, revoke va audit yo‘lisiz yoqilmaydi.
